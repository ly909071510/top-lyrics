# Top Lyrics

macOS 菜单栏桌面歌词条：横置于屏幕顶部菜单栏「帮助」菜单右侧，字号与颜色与系统菜单文字一致，安静地显示当前歌曲与两句歌词。

支持 **Apple Music（「音乐」App）** 与 **QQ 音乐** 双来源自动跟随，哪个在播就跟哪个。

主要面向 **Mac 桌面端**（iMac / Mac mini / Mac Studio 或外接显示器）使用。

## 特色功能

- **原生菜单栏横条**：贴在「帮助」右侧，不占程序坞、不弹独立窗口；按前台 App 菜单的长短自动伸缩，永不遮挡右侧系统图标
- **三区固定布局**：区域 1 歌曲信息（封面 + 歌名 + 歌手）、区域 2 当前句、区域 3 下一句；位置永不移动，只换内容，换句时在原位约 0.6 秒淡入淡出
- **双来源自动跟随**：Apple Music 与 QQ 音乐哪个在播放就显示哪个（两边同时播放时优先 QQ 音乐）；QQ 暂停或退出时自动回落到「音乐」
- **逐字扫光（推算版）**：当前句唱到哪个字、哪个字变亮，卡拉 OK 式扫过
- **当前句 / 下一句分级显示**：下一句字号更小、颜色更淡，与当前句形成主次；字号（70%–100%）与透明度（30%–100%）均可在设置中用滑杆调节
- **槽内滚动**：过长的歌名与歌词在各自区域内匀速滚动，速度可调；歌词行只在轮到它唱（成为当前句）后才开始滚动，下一句始终静止显示；歌名滚动 30 秒后自动回开头停住，悬停可再触发
- **可拖拽分隔条**：三个区域的宽度可拖动调整、双击复位并持久保存；分隔条平时自动隐藏，鼠标划过横条时才淡入
- **帧率可调**：30 / 60 / 120 fps 三档，由显示器 vsync 驱动；无滚动、无扫光时自动停止刷新，不费电
- **歌词多源**：QQ 音乐来源优先使用 QQ 曲库的同步歌词，缺失时自动查询 LRCLIB；Apple Music 来源歌词来自 LRCLIB
- **首启授权向导**：缺哪项授权，启动时自动弹出向导，实时显示状态，点按钮直达系统设置对应页；右键菜单随时可重开
- **歌词偏移校准**：歌词与演唱不同步时，设置里用 ±5 秒滑杆微调，两个来源统一生效
- **失败不静默**：没匹配到歌词显示「歌词未找到」、断网显示「歌词加载失败」；右键菜单可「重新获取歌词」，也能「导出诊断信息」方便反馈问题

## 安装与使用指南

**系统要求**：在 macOS 27 上开发与测试，理论支持 macOS 14 或更高版本（其他版本未经实测）。

### 方式一：一键安装脚本（推荐）

1. 下载 Release 的 zip 并解压
2. 双击解压出的 **`安装.command`**。应用未做签名公证，macOS 会弹出「Apple 无法验证……恶意软件」的拦截框且**没有「打开」按钮**，先点「完成」，再去 **系统设置 → 隐私与安全性 → 安全性设置**，拉到「安全性」一栏点「**仍要打开**」，输密码确认后脚本才会真正运行（每个未签名程序第一次都这样，与程序本身是否安全无关）
3. 脚本会自动完成：去除应用的下载隔离标记 → 把 `Top Lyrics.app` 拷进「应用程序」→ 打开系统设置的授权页 → 启动应用
4. 应用启动后若授权未齐，会自动弹出**授权向导**，跟着向导点完两项即可（见下方「授权」）

> 说明：辅助功能等权限是 macOS 的安全设计，**任何程序都无法替用户授予**，只能由用户本人在系统设置里点。脚本已经把能自动化的都自动化了，授权那两下点完即一劳永逸（直到下次更新版本）。

### 方式二：手动安装

1. 将 `Top Lyrics.app` 拖进「应用程序」文件夹
2. 首次双击启动会被系统拦截（未签名公证）：点弹窗的「完成」，再去 **系统设置 → 隐私与安全性 → 安全性设置**，在「安全性」一栏点「仍要打开」并输密码确认，之后就能正常启动
3. 完成下方「授权」两步

### 授权

启动 Top Lyrics 后，若授权未齐会自动弹出向导，窗口里实时显示每项状态，点对应按钮即可直达设置页：

1. **辅助功能**：在「允许辅助应用程序控制电脑」（设备控制和数据访问）页，点 **+** 添加 Top Lyrics 并打开开关
   - **更新版本后必须重做**：先把列表里的旧条目用 **−** 删掉、再重新添加，授权才对新版本生效（开关显示开着不算数）
2. **自动化**（仅 Apple Music 来源需要，只用 QQ 音乐可跳过）：在「音乐」App 播放时若弹出「Top Lyrics 想要控制音乐」，点「好」允许

随时可通过右键横条 →「授权设置…」重新打开向导确认状态。

### 日常使用

- 打开「音乐」或 QQ 音乐播放歌曲，横条会自动跟随；不需要任何额外操作
- 右键点横条 →「设置…」：可调滚动速度、帧率档位、下一句字号与透明度、歌词偏移，全部实时生效并自动保存
- 右键菜单还有「重新获取歌词」（当前歌曲重新匹配）、「导出诊断信息」（复制到剪贴板，方便反馈问题）
- 拖动区域之间的分隔线可调宽度，双击分隔线恢复自动宽度
- 右键点横条 →「退出 Top Lyrics」退出；也可将其加入登录项开机自启

### 常见问题

- **横条不出现**：先右键横条（或重新启动应用）打开「授权设置…」看向导里哪项没过；最常见的是更新版本后辅助功能没删掉重加
- **歌词不跟、显示为空**：检查自动化授权（系统设置 → 隐私与安全性 → 自动化 → Top Lyrics →「音乐」开关）
- **QQ 音乐不跟随**：确认 QQ 正在播放（不是暂停），且辅助功能授权已按当前版本删掉重加
- **歌词对不上或缺失**：先试右键菜单「重新获取歌词」，再用设置里的「歌词偏移」微调；仍不行多半是网络曲库的版本 / 覆盖问题，属已知局限（见下）

## 工作原理（简述）

- 通过 macOS 系统提供的接口读取「音乐」App 与 QQ 音乐的播放信息
- 歌词按歌名、歌手与时长向网络曲库匹配带时间轴的歌词

## 局限性

- **设备适配**：主要针对桌面 Mac 与外接显示器。带刘海（Notch）的 MacBook 菜单栏左侧空间有限，当前台应用菜单项很多时，横条可能被压缩、让位或隐藏，体验不保证
- **不支持网易云音乐**：其 Mac 版界面为自绘，辅助功能读不到任何界面元素；系统级「正在播放」通道在当前 macOS 上又对第三方应用封闭，两条路均不通
- **逐字亮不是真逐字**：QQ 曲库与 LRCLIB 只提供逐句时间轴，没有逐字时间戳；扫光按句内各字宽度比例匀速推算，**每句头尾精确**，句内唱得忽快忽慢或拖长音时会暂时飘移，下一句自动重新对齐
- **QQ 音乐进度为推算值**：手动拖动 QQ 进度条后，扫光位置会短暂失步，切歌后自动校准
- **歌词可能对不上**：Apple Music 自身歌词受 DRM 保护无法读取，歌词来自网络曲库；个别歌曲可能出现版本不一致、缺词或匹配错误，中文歌曲覆盖相对薄弱
- **依赖系统授权**：需要辅助功能与自动化两项授权（见上）；QQ 音乐日后改版若改动播放栏结构，读取可能失效
- **未签名公证**：应用未做 Apple 签名与公证，首次运行安装脚本或应用会被系统拦截，需在 系统设置 → 隐私与安全性 → 安全性设置 里点「仍要打开」（见安装指南）
